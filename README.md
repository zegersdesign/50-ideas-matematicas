# 50 Mathematical Ideas — Agent Skill

Skill para agentes (Claude Code, Copilot CLI, Amp, OpenCode y otros compatibles con Agent Skills) generado a partir del libro *50 Mathematical Ideas You Really Need to Know* de **Tony Crilly**, con [book-to-skill](https://github.com/virgiliojr94/book-to-skill).

Convierte las **50 grandes ideas** del libro en una base de conocimiento consultable: números y constantes (0, π, e, infinito), teoría de números (primos, Fibonacci, áureo), geometría y topología, cálculo, probabilidad y estadística, álgebra abstracta (grupos, matrices, códigos), matemática de decisión (juegos, optimización) y grandes problemas (Fermat, Riemann).

## Instalar en cualquier host de Agent Skills
```
npx skills add https://github.com/<owner>/50-ideas-matematicas --skill 50-ideas-matematicas
```

## Contenido
- `SKILL.md` — marcos centrales + índice de capítulos + índice de las 50 ideas
- `chapters/` — 10 capítulos temáticos que agrupan las 50 ideas
- `glossary.md` — términos clave
- `patterns.md` — demostraciones y técnicas
- `cheatsheet.md` — fórmulas, constantes y reglas de decisión

El contenido son **resúmenes sintetizados** (ideas, intuición e historia), no el texto del libro.
